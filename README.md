# motorola-acia-6850

The Motorola MC6850 asynchronous communications interface adapter.

| Crate | Registry |
|---|---|
| [`emu198x-motorola-acia-6850`](crates/emu198x-motorola-acia-6850) | [crates.io](https://crates.io/crates/emu198x-motorola-acia-6850) |

Part of [Emu198x](https://github.com/emu198x/emu198x), a family of
cycle-accurate retro-computing emulators. Used by the Atari ST, for its keyboard and MIDI links.

Each crate is versioned on its own and bumps only when it changes. Releases go
through release-plz: merging its release pull request tags the crate and
publishes it.
